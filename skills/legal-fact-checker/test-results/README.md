## 읽을 때 주의

- TC-1~5는 **v1 당시 기록을 그대로 둔 것**입니다. 옛 커넥터 이름('법정보조회시스템')과 v1 체인 도구 이름(`chain_full_research` 등)이 나오며, 조회 시점(2026.4.28.) 기준 내용이라 이후 개정은 반영되어 있지 않습니다. 법적 근거로 그대로 쓰지 마십시오.
- 공개를 위해 작성 주체·문서번호의 회사명, 특정 현장명과 발주기관명은 `○○`·"공공기관" 등으로 일반화했습니다. 법령 내용은 바꾸지 않았습니다.
- v1에서 "별표 전문 미반환"으로 남았던 항목(TC-1, TC-4)은 v2의 `get_annexes`로 조회되는 것을 TC-6에서 확인했습니다. 고시 전문 미반환 항목(TC-3, TC-5)은 v2에서 `execute_tool`의 `search_admin_rule`·`get_admin_rule` 경로를 안내하며, 별도 재시험은 하지 않았습니다.
